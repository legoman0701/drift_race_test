## Controls

### In Menu
- **H** : host a new game
- **J** : join a game

### In Game
- **Mouse** : activate in settings and let the car follow your mouse cursor
- **Up, Z** : move forward
- **Down, S** : move back
- **Left, Q** : turn left
- **Right, D** : turn right
- **Space** : handbrake
- **Esc** : open settings
